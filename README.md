# Vinayaka N Walishettar — VNW100 Portfolio
Static site (no build step). Open `index.html` or deploy the folder to Vercel/Netlify/GitHub Pages.

- `index.html` — all sections (Hero, About, Skills, Projects, Timeline, Milestones, Certificates, GitHub, Contact)
- `style.css` (minified, single request)
- `script.js` — vanilla JS, deferred, no dependencies
- `img/` — WebP images (projects, certificates, portrait) and SVG skill icons

Edit contact links in `index.html`; replace the "Coming soon" demo modals by pointing project links to real URLs.
